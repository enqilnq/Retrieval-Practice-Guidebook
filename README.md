# 🌴 Retrieval Practice Guidebook: The Learning Jungle

An interactive EdTech web application exploring the cognitive psychology of learning. This project is designed to help learners and educators overcome the "Fluency Trap" and master the science of retrieval practice through engaging, interactive challenges. 

Designed and engineered as part of an M.Ed. Instructional Design portfolio at UT Austin.

## 🎯 Project Overview

This guidebook translates complex cognitive psychology principles into an accessible, interactive jungle-themed adventure. It guides users through four key pedagogical stages:

* 🐒 **The Monkey Trap (Jungle Myths):** Debunking the "Fluency Trap" and common illusions of learning like passive re-reading, highlighting, and cramming.
* 🐯 **The Tiger Gym (The Retrieval Secret):** Demonstrating the power of "pulling out" information (retrieval) over simply "putting in" (encoding) through a live, interactive Brain Dump exercise.
* 🦌 **Deer's Choice Forest (Reclaiming the MCQ):** Showcasing how Multiple Choice Questions act as powerful retrieval boosters via "Discriminative Retrieval."
* 🐻 **The Master Bear (Feedback):** Emphasizing the critical role of immediate, formative feedback in correcting misconceptions and reducing cognitive anxiety.
